# 📺 STB 客廳電視盒 (stb-livingroom)

**專為家中長輩設計的客廳智慧電視盒軟體** —— 將淘汰的二手 PC、迷你主機或樹莓派（Raspberry Pi）轉化為大螢幕影音播放器。手機只需掃描一次螢幕上的 QR Code，即可變身為**超大字體、高對比、支援語音輸入的 PWA 虛擬遙控器**。

---

## ✨ 核心特色

- **🪶 極致輕量、非獨佔模式 (Non-Kiosk)**：
  - 採用 **Rust + Tauri v2 + Axum** 架構，記憶體佔用極低、無須安裝 Node.js。
  - 平時最小化常駐於電腦系統匣（Tray Icon），不影響一般電腦日常使用；長輩點開手機遙控器即可一鍵喚醒電視畫面，按 `Esc` 或手機「🚪 關掉電視回電腦」立即暫停影片並退回桌面。
- **📱 首次掃碼、永久記憶（免重複掃 QR Code）**：
  - 首次啟動於系統本地應用資料夾動態產生隨機配對金鑰（不硬編碼於原始碼）。
  - 手機掃描一次 QR Code 並「加入主畫面」後，憑證自動存於手機 `localStorage` 並隱藏網址參數，日後點擊桌面圖示即可直接連線。
- **👵 專為長輩打造的適老化遙控器與觀影體驗**：
  - **台灣常用新聞直播與老歌頻道牆**：內建台視、民視、中視、華視、公視、東森、三立、TVBS 新聞 24 小時直播（智慧自動尋址 `LIVE` 串流，不怕直播換網址）與經典國台語老歌。
  - **語音搜片 + 編號選片**：支援手機麥克風語音搜尋，可選擇「▶️ 搜尋並直接播」或在電視列出結果並以手機點擊 `[1]~[6]` 編號選片。
  - **自動與手動雙重略過廣告**：背景自動偵測跳過廣告；另於手機端提供醒目的橘色 **「⏭ 略過廣告（點右下角）」** 大按鈕，結合作業系統底層真實滑鼠點擊（`isTrusted: true`）與倍速快轉。
  - **適老化黃色大字幕 & 語速控制**：一鍵開關 CC 字幕並自動放大為 `36px` 高對比黃色粗體字；提供 **「🐢 放慢 / ⚡ 正常 1x / 🐇 加快」** 三鍵直覺語速控制。
  - **系統主音量與防休眠整合**：直接控制作業系統總音量、電視頂部超大 OSD 狀態提示、手機按鍵震動回饋，以及播放期間自動防休眠（Keep Awake）。

## 🚀 快速開始與跨平台打包

### 1. 直接下載雲端預編譯執行檔（GitHub Actions）
本儲存庫已配置 [`.github/workflows/build.yml`](./.github/workflows/build.yml) 跨平台自動打包流程。請至上方 **[Actions](../../actions)** 頁籤點選最新一次建置，於頁面底部 **Artifacts** 下載對應系統版本：
- 🪟 `stb-windows-x64`（Windows 10 / 11 單一可攜式 `.exe`）
- 🐧 `stb-linux-x64`（Ubuntu / Debian x86_64）
- 🍓 `stb-raspberrypi-arm64`（樹莓派 Raspberry Pi 4 / 5 64-bit ARM64）
- 🍎 `stb-macos-arm64`（macOS Apple Silicon）

### 2. 本地編譯與啟動
```bash
# 開發模式啟動
cargo run

# 執行自動化單元與整合測試
cargo test

# 編譯正式版最佳化單一執行檔
cargo build --release
```
